# Canonical Fixture Data

These are normalized, machine-readable project fixtures, not copies of raw
source assets. They are distributed under this repository's GPL-3.0-or-later
license with the provenance notice in `../NOTICE.md`.

- `langton/transitions-cneswc.json`: 219 base transitions in center, north,
  east, south, west order; SHA-256
  `c0ca8e6c9218ddd2603905b6dbc5f3170a7f3f32405b8ad5290b1e396018ee92`.
- `langton/seed.json`: the `15×10`, 86-cell canonical seed; SHA-256
  `46faf1f1c0c4b966f139c59134cc00697b45f4156a1f51a6c4fa2e3d27d5bda1`.
- `oracles/golly-3.3/`: normalized state snapshots independently generated by
  Golly 3.3's `bgolly` RuleLoader executor. Each was run twice before being
  frozen. They use the active-bounds origin, sorted `y,x,state` cell order,
  and carry a state-set SHA-256.

The public fixture set intentionally excludes raw papers, Golly package bytes,
Golly rule/RLE source files, and rendered images.
